# Game

Экраны 7–11 макета: выбор тренера, раунд, итог раунда, добор и результат матча, а также диалоги «Сдаться?» и «Соперник переподключается».

Публичный API: `GameTable`.

Пока нет игрового сервера, партия идёт в браузере: `useLocalGame` повторяет логику прототипа, а за соперника ходит бот с именем настоящего соперника. Когда сервис будет готов, заменить надо только `useLocalGame` и `rules/catalog.ts`, а экраны останутся. `rules/strength.ts` останется как прогноз силы на клиенте.

Карты нарисованы по макетам из PDF: картинки лежат в `public/cards` (игроки трёх редкостей, тренеры, бафы и дебафы, рубашки), имя, сила и текст способности уже есть на картинке. `GameCard` показывает картинку и подпись для скринридера, а `rules/catalog.ts` связывает карту с картинкой и содержит её силу и стихию.
