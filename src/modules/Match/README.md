# Match

Экраны 4–6 макета: лобби, приглашение и «Соперник найден». Состояние матча приходит с сервера через long-poll.

Публичный API: `CreateMatchButton`, `MatchRoom`. Когда соперник найден, `MatchRoom` рисует слот `game`, а от других модулей не зависит. Слот `player` нужен для значка игрока в шапке.
